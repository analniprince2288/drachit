# ДРАЧИТЬ III — Хроники Бесконечности

Одностраничная браузерная RPG с ручным действием, автоматическим накоплением, сражениями, классами, экипировкой, развитием персонажа, заданиями и достижениями.

## Возможности

- Три класса с разными бонусами: Рыцарь нажима, Архонт цикла и Берсерк печати.
- Четыре режима накопления: ручной, автоматический, турбо ×4 и хаос.
- Ручное действие кликом на центральную печать, кнопку или пробелом.
- Три области с открытием по уровню, обычные экспедиции и доступный после двух побед бой с владыкой.
- Боевой режим: здоровье, энергия, вражеские атаки, усиленный удар, эликсиры, отступление, добровольный автобой.
- Опыт, уровни, монеты, инвентарь и три ячейки экипировки.
- Девять заданий, восемь достижений, кузница улучшений, журнал событий.
- Автосохранение в `localStorage`, экспорт и импорт JSON-сохранения.
- Автоматический перенос прогресса из v2 (без удаления старого сохранения).
- За время отсутствия можно получить до 24 часов автоматического накопления; расчёт производится при следующем посещении сайта. Бои вне открытой активной вкладки не симулируются.
- Русскоязычный интерфейс. Никаких сторонних зависимостей, запросов к серверу или баз данных.

## Запуск локально

Распакуйте архив и в папке с `index.html` выполните:

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`.

## Деплой на Vercel

1. Установите Node.js, если он не установлен.
2. В терминале откройте папку с `index.html`, `game.js`, `style.css` и `vercel.json`.
3. Выполните:

```bash
npm install -g vercel
vercel login
vercel --prod
```

Либо импортируйте папку через GitHub в Vercel: пресет `Other`, сборка не нужна, корневая папка — директория с `index.html`.

## Примечания

- Прогресс хранится локально в том браузере и на том домене, где запущена игра. При смене домена переносите его через вкладку «Летопись» → «Экспорт сохранения» / «Импорт сохранения».
- Локальное открытие файла через `file://` в зависимости от браузера может ограничивать localStorage; рекомендуем HTTP-сервер.
- Автоматическое накопление при закрытом сайте не создаёт фоновых процессов на сервере.
